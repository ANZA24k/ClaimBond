# Contributing

Keep this repository centered on a reusable Intelligent Contract. Changes to source
policy, agreement rules or economic behavior require a protocol-version review.
Maintain tests using the exact pinned runner and official genlayer-test; distinguish
mocks, native simulation and hosted Full Consensus. Never commit account keys.
Run pytest and every linter/schema check before proposing a source change.
Document adapter transport limits honestly. Production deployment needs a separate
security review, including account-code checks and message-failure recovery.
